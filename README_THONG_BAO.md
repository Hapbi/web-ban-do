# Thông báo góc trên bên phải

Đã chuyển thông báo TempData `Msg` và `Err` thành toast cố định ở góc trên bên phải màn hình. Toast có biểu tượng, tiêu đề, nút đóng và tự ẩn sau khoảng 5,5 giây.

Các file được cập nhật:
- `Views/Shared/_Layout.cshtml`
- `wwwroot/css/notifications.css`
- `wwwroot/js/notifications.js`

Sau khi giải nén và mở đúng project, dừng bản đang chạy, chạy lại ứng dụng rồi nhấn `Ctrl+F5` trên trình duyệt để tải CSS mới.
