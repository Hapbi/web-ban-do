# Sửa lỗi ảnh sản phẩm

- Thêm bộ ảnh SVG cục bộ để làm ảnh dự phòng theo nhóm sản phẩm: robot hút bụi, đồ gia dụng, dụng cụ cầm tay, máy sấy tóc, máy ép/xay trái cây.
- Trang chi tiết và thẻ sản phẩm dùng ảnh dự phòng phù hợp nếu URL ảnh bị hỏng hoặc không tải được.
- Các sản phẩm seed cũ đang dùng picsum hoặc không có ảnh được đổi sang ảnh local.
- Ảnh dự phòng nằm trong `wwwroot/images/products/`. Có thể thay các SVG bằng ảnh sản phẩm thật cùng tên file nếu muốn.
- Nếu sản phẩm đang có URL ảnh ngoài nhưng URL đó bị lỗi, trang sẽ tự chuyển sang ảnh dự phòng cục bộ.
